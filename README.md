## Featured Projects

### [Retail Sales Data Analytics](https://github.com/muneebsaddal/retail-sales-data-analytics)
A complete retail data analysis project using Power BI — uncovering sales performance, seasonal patterns, and pricing strategy impact across fashion brands.  
**Tech:** Power BI, DAX, Excel, SQL  

### [OpenSky Flight Data Analysis](https://github.com/muneebsaddal/opensky-flight-data-analysis)
Analyzed live flight tracking data from the OpenSky API using Python to study aircraft movement, flight density, and performance trends.  
**Tech:** Python, Pandas, Matplotlib, API Integration  

### [Sample Sales Data Analysis](https://github.com/muneebsaddal/Sample-Sales-Data-Analysis)
Performed data cleaning, transformation, and visualization on sample business sales data to identify regional performance and customer insights.  
**Tech:** Power BI, Excel, SQL
